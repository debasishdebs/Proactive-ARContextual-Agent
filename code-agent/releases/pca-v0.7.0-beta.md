## v0.7.0-beta

Wave 1: motion-aware keyframe capture and image memory on the Rokid glasses, with the phone app storing and searching the photos (Room v2, additive migration).

- Glasses decide when to take a photo from head motion, stillness and novelty, instead of a fixed timer.
- Keyframes go to the phone, which keeps them with captions and lets you ask about them.
- Debug build, for testers with adb. Previously tagged v1.0.0-rc1 (renamed: it was never a release candidate). Superseded by v0.9.0-beta, which contains everything here plus about 340 later commits.

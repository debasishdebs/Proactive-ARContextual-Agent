1. **Critical — Phases 1–2 create derived data before its deletion protection exists.**  
   **Location:** lines 244–246, 275–284. Phase 1 materialises sensor features; phase 2 makes Moment outputs and scores usable; cleanup and edge writers arrive only in phase 3. Forget during either earlier phase can leave these copies behind.  
   **Exact edit:** Move source-to-projection cleanup, transactional fences, Delete-all integration and required provenance into the phase introducing each writer. Keep phase 3 for unified entry points and remaining backfill. Require Forget/racing-write tests at every materialising phase, or explicitly prevent activation until phase 3 completes.

2. **Critical — Deletion discovery still depends on the rebuildable projection being complete.**  
   **Location:** lines 169, 188–199, 208, 257. Frames and memories are collected from `moment_part`; range deletion selects existing `moment` rows. A source committed before its asynchronous projection, or omitted by a defective builder, escapes. Existing `forgetRangeTx` only handles traces, labels and their dependants; it does not discover those missing frames/memories.  
   **Exact edit:** Discover sources independently from authoritative stores using canonical occurrence times and source relationships, union them with projection references, and tombstone requested seconds even when no Moment exists. Persist the outward-rounded full-second fence used by the cascade. Add tests with empty/stale projection tables and a source arriving concurrently.

3. **Critical — Whole-trace deletion leaves other Moments and their outputs alive.**  
   **Location:** lines 85, 176–211, 229–232. `CanvasSlice3Dao.forgetRangeTx:49–50` tombstones an entire overlapping trace. Forgetting Moment A therefore removes the trace supplying Moment B, but the proposed cascade only removes projections and edges rooted in A. B’s sensor vector, completed outputs and an in-flight B writer can survive; B itself is not tombstoned. Direct trace deletion and retention have the same problem.  
   **Exact edit:** Retain indexed trace-source dependencies alongside Moment roots. Every trace tombstone/reclaim/revision change must remove affected sensor projections, invalidate/delete dependent outputs, void jobs and enqueue cleanup. Check captured trace revision, tombstone and persisted epoch at payload release and result commit. Preserve 3b’s source checks rather than replacing them with Moment tombstones.

4. **Critical — The proposed edge table does not yet define a complete dependency closure.**  
   **Location:** lines 128, 175–201. `sourceMomentId` permits only Moment roots; downstream derivations must inherit all upstream roots, but that obligation is absent. The type list and cascade also omit explicit handling for trained classifiers, learned embeddings/calibration and several listed targets such as `EXPORT` and `HELPER_JOB`. Calling these objects “config” does not remove their user-data dependency.  
   **Exact edit:** Specify either recursive typed-source edges or mandatory transactional inheritance of the complete root set through every derivation, including shared model-call batches. Add exhaustive per-type deletion/invalidation policies. User-trained artifacts must be disabled and removed or rebuilt without forgotten inputs; their downstream outputs and deployed copies must follow. Separately identify immutable pretrained/config artifacts that contain no user data.

5. **Important — After-commit notifications are not a durable, idempotent cleanup mechanism.**  
   **Location:** lines 205–217. `ForgetListeners` is in-memory and swallows ordinary listener failures. `FrameSweep` retries phone JPEG removal; it does not recover lost device notifications or arbitrary export cleanup. `CanvasForgetCoordinator.trySend:68–69` does not persist an unsent range request. On retry, the deleted Moment’s references may already be gone.  
   **Exact edit:** Insert durable cleanup/outbox records in the deletion transaction, retaining paths, wire frame ids, trace ids and mapped ranges until acknowledged. Recover them on startup/reconnect. Explicitly cover glasses `OutboundBuffer`, trace files and queued marks: `onFramesForgotten` currently only sweeps phone trace folders, while `MarkOutbox.onEpoch` clears marks on epoch changes, not range Forget. Retain 3b’s laptop cleanup journal/ack lifecycle. Replace “Watch: none exists” with the existing LiveFit integration inventory (`WatchSource`, `WatchMotionIntake`) and an explicit contract for any remotely retained data; its current deletion capability is unverified.

6. **Important — Uncertainty widening can miss precisely the data it is meant to protect.**  
   **Location:** lines 156–158. Taking maximum uncertainty from already-selected candidates misses an adjacent part whose uncertainty interval overlaps the requested range. The five-second cap also under-deletes valid mappings: `ClockMap` incorporates sample ages up to 120 seconds. Falling back to glasses wall plus uncertainty does not correct an unknown phone offset.  
   **Exact edit:** Select by interval overlap, such as `partTime − uncertainty <= to && partTime + uncertainty >= from`, without silently truncating the uncertainty. Define conservative handling for unknown/unbounded mappings. For `canvas_trace`, add the required clock-quality/uncertainty schema, backfill existing rows and update both import admission and Forget overlap checks. Do not compare unmapped glasses times with phone ranges. The defect at `TraceImport.kt:87` is real.

8. **Important — Feature reuse passes the wrong timestamp to the classifier.**  
   **Location:** lines 92, 98, 276–277. Live `SensorFeed:111–115` passes sensor time. `TraceRecords:73–77` explicitly says replay feeds `sMs` to the classifier and uses `tMs` for scheduling. Delivery-time batches collapse sample spacing, changing rotation, acceleration windows and step frequency.  
   **Exact edit:** Traverse events in append order but pass their `sMs` to classifier methods. Define configuration restoration, warmup and partial/downsampled quality. Describe canonical-window features separately from exact live tick parity, since live ticks are `postDelayed(1000)`. Use fixed independent golden expectations; comparing two executions of the same mutated classifier does not establish a useful golden test.

9. **Important — Elapsed-second aggregation does not produce phone-second features.**  
   **Location:** lines 98–101, 162. Mapping only an elapsed bucket’s start assigns its entire vector to one phone second. With a +500 ms offset, elapsed `[1000,2000)` maps to phone `[1500,2500)`, spanning two Moments. Keeping whichever bucket has more samples discards relevant data.  
   **Exact edit:** Define feature reset/emission boundaries in canonical phone time, using the mapping to schedule corresponding elapsed boundaries. Specify exact-boundary ordering, final partial windows, gaps and overlapping traces. Define `moment_sensor`’s complete primary key and deterministic arbitration when multiple traces cover a second.

Bind estimate/start to input kind, graph hash, selected ids and captured content/source revisions; re-resolve at start. Carry captured provenance through confirmation, payload release and result commit. Treat `derived_from` as deletion lineage, not a replacement for verified source identity and freshness.

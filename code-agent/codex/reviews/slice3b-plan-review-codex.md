1. **Critical — T4/T9a: the proxy is not yet an enforced network boundary.** A normal network plus `HTTPS_PROXY` lets generated code ignore the proxy and contact the LAN or internet directly. T3’s blanket “never bind/listen” test also contradicts the host proxy.
   **Edit:** “Specify and prove the macOS VM/network topology before generation: gen can reach only the proxy; deny direct IPv4/IPv6, external DNS, host/LAN services and runtime APIs. Proxy permits exact API hosts on port 443, rejects private destinations, and fails closed.” Distinguish the proxy listener from a helper job listener. [Podman network semantics](https://docs.podman.io/en/latest/markdown/podman-network-create.1.html#internal).

2. **Critical — T7a/T9a: host-side processing can undo container isolation.** A generator can modify scratch `.git/config` to invoke a malicious filesystem monitor when the host later runs Git. A nested output symlink can escape collection even when the final file uses `O_NOFOLLOW`.
   **Edit:** “Never invoke Git, generated scripts or builds against generator-controlled metadata on the host. Produce the diff inside isolation; apply it only to a fresh verify snapshot. Collect after container termination using directory-relative traversal rejecting symlinks in every component, special files and unexpected hardlinks; bound depth, count and bytes before reading.”

3. **Critical — T1/T2: confirmation is not defined as native user presence.** A route that excludes helper tokens but accepts browser tokens allows the submitting browser to confirm its own build. Also, `promote` is “reserved/default off,” although S39/S55 require it for `tool_build`.
   **Edit:** “Grant `py_exec` and `promote` independently in native app UI, both off initially. Native confirmation binds one immutable job/bundle hash, session and expiry; browser/helper credentials cannot mint it. Require `promote` for tool-build leasing and result submission.”

4. **Critical — T2/T3/T4/T11: cancellation and deletion lack a complete failure path.** After LAN loss or token revocation, polling may fail before delivering cancellation; a blocked runner may prevent heartbeats. Helper death can leave a container running. A 60-second lease alone cannot ensure termination within five seconds.
   **Edit:** “Run supervision independently of execution; bound network calls; kill on denied heartbeat, local lease deadline or connection failure according to an explicit ≤5-second policy. Add runtime-enforced deadlines and orphan recovery. Persist cleanup commands independently of deleted job rows; test Forget racing with result commit and lost acknowledgements.”

   **Edit:** “Use one named, inspected rootless Podman connection; refuse unsupported isolation settings. Verify effective mounts/namespaces/seccomp and resource enforcement at execution.

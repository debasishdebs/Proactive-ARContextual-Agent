5. **Important — Ask debug GET can return forgotten content after redaction/wipe completes.** [AskDebug.kt:104](/Users/debasishkanhar/Desktop/rokid/pca-s2/int/android-companion/services/orchestration/src/main/java/com/rokid/context/canvas/AskDebug.kt:104)

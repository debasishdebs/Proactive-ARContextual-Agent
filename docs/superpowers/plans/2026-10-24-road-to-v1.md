## 3. Decision register (so v0.9.x work does not re-open them)
**Moments/Scenes** (full text in `2026-10-24-moment-scene-design-decisions.md`): MomentId = 8 hex digits of the phone-clock epoch second (default; 10 open); stored Moments ON by default with a kill switch; a second with no live photo or any photo without capturedAtMs is not a Moment; an overfull second (> 2000 photos) is refused; builder trigger coalesces per second with a 15-minute cadence worker for the previous and current hour; Forget finds Moments from the authoritative stores, writes tombstones and a durable range fence, queues outbox rows in the same transaction; Delete all keeps the outbox and adds one ALL command; audit rows are content-free and die with their object; `object_derived` holds summary/caption/embedding and a stale field is hidden at once; derived writes carry fence + inputSeq; a parent part change stales the parent in the same transaction; QUARANTINED traces are hidden from every reader, still deleted by every Forget, promoted by a mapped import; coarse uncertainty for unmapped traces = 24 h. Scene: references not copies; children keep their own summaries, the Scene holds the collective ones; activity and sensor separate; boundaries by hour window + activity change (else hash distance 25% or embedding similarity < 0.75) + 5-minute cap, with the cut reason stored; rebuild cadence user-configurable with a warning; Audio later with the same interfaces.
**Canvas** (`2026-10-24-3c-expression-editor-design-decisions.md`, `2026-10-24-composite-nodes-design.md`, `2026-10-24-generic-flow-families.md`): guards only first and SHADOW/TRIAL only; expression graph JSON = `{steps:[{name,inputs,nodes,wires,out}],out}` (documented in the 3c plan section 10, golden hash d57e69230cf7); wiring by pickers, boxes outer / inner graph on open; `strict=false` composite params so old pipelines keep running; Confidence check defaults mean >= 0.70 from one constant `LocalTrust.DEFAULT_CUTOFF`; built-in Default capture compiles to the identity plan f5782e0d8610 and is never active by existing; merged view links by signal name plus a dashed captured-frames link; palette will be regrouped into Source/Aggregate/Process/Condition/Outcome with lanes as an attribute.
**Process rulings:** see HANDOFF section 0 (threat model A, Codex as reviewer, memory-only helper token, per-run py_exec confirmation, frames only for 3b Python, NL tools to v2, hostile-code hardening to 3d, M1 gate numbers, hand-over wear window from heartbeat `chg=`).

## What changed
- ai module: node types `input.utterance`, `embed.text`, `trigger.summarizer_pass`, `rag.retrieve`, `gate.nudge`, `out.deliver` (schema 2, ASYNC), port type RAG, stub triggers `trigger.moment/scene/signal/schedule` (palette off, not liveable). `FlowPlan` (shape rules, `compile`, `BUILT_IN_QUERY/NUDGE`), `RagRetrieveParams` (mirror of `RagParams.SCHEMA`, a test keeps them equal), built-ins `default-query` and `default-nudge`. `PipelineValidator` treats flow roots as input roots and adds `FlowPlan.shapeProblems`.
- orchestration: `FlowPlans` seam; `AnswerService.retrieve(.., plan)` and `NudgeInputs.build(.., plan)` run the same code for the built-in plan and a compiled pipeline; `AnswerService`/`NudgeEngine` look the published plan up and fall back to the built-in on any lookup or retrieval error. `CanvasPublisher.publishFlow` (kind `flow`, component `query|nudge`, supersedes the same component, rollback = the mark). `DaoFlowPlans` (cached per publish id). `CanvasDao.activeFlow` (a query only, no Room change).
- phone: `POST .../publish {"mode":"flow"}`, `flow` flag on version rows, publish dialog shows only the flow mode for a flow version.

## Decisions to know
- Live delivery targets: Query `caller`, Nudge `both` (today's verbosity routing). `phone`/`glasses` are saved and edited but publish says "not live yet" (slice C).
- Prompt in a flow is the live ANSWER/NUDGE prompt only (draft text refused). No "run first" publish gate (a flow edit changes retrieval inputs only).
- Nudge built-in plan has `imageQuery = true`: the photo store joins when a trigger gives a vector, exactly as before (no trigger does yet).
- `gate.nudge` is a required, param-less node: quiet hours, cap, dedupe, shown-gap and the Forget commit fence live in `NudgeEngine`/`AnswerService` and cannot be edited out.
- JS size budget raised 4668 -> 4670 (format.js MODES entry, versions.js mode filter).

## Codex review fixes
- A Query may read `recent`/`history` through RagCore (their lines join the memories block); a Nudge refuses `memories`/`photos`, a Query refuses `imageQuery` (never silently ignored).
- A flow's `ai.prompt` with a top-level `template`/`schema` is a validation problem (prompt text comes from Settings); the flow mode text says so. JS line count unchanged.

- Ask carries `historyIds` as `Retrieved.fenceIds`: in the commit fence, and stored as the row's `dependsOn` (same mechanism as a nudge, no Room change).

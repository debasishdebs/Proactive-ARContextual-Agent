# v0.9.8 slice A handoff (2026-10-28)

## What changed
- New `RagCore` (services/orchestration, package orchestration): `retrieve(RagQuery(text?, vector?), List<RagSource>, RagParams, nowMs) -> RagContext`. Never calls an LLM.
- Sources are lazy descriptors: `MemoryStore`, `PhotoStore`, `RecentWindow`, `NudgeHistory`, `Explicit`. Every source goes through the Forget fence, the photo gate (AskPhotoPolicy, endpoint check, decrypted images, fail closed) and the bounds inside the core.
- `RagParams`: every field optional (mode, fusion, semanticWeight, rrfK, topK, poolSize, minConfidence, recencyBoost, halfLifeDays, maxChars, maxRecent); null = the user's setting / built-in default. `RagParams.SCHEMA` (name, type, min, max, options, default, doc) is for the canvas editor.
- `AnswerService.retrieve/retrieveScored/debugPhotoRecall` delegate to RagCore (Ask = MemoryStore + PhotoStore). `NudgeInputs.build` uses RecentWindow + NudgeHistory (6 h, newest 10, same line format); new optional `photoVector` arg (IMAGE path) is not wired to any trigger.
- `PhotoRecall.search` got an optional `queryVector` (skips the text embed); `RagCore.photosByVectorFrom(context)` is the production binding, unused so far.
- Spec Core section updated to the sources/params design.

## Tests
- `RagCoreGoldenTest`: goldens in `src/test/resources/golden/ragcore` were captured from the pre-refactor code (separate first commit) and pass unchanged after the refactor: Ask plain / photos / fallback, retrieveScored hit / fallback, Nudge plain / extra. Plus `allNullParamsEqualToday`.
- `:services:orchestration:test :services:memory:test` green.
- Existing `AnswerServiceDebugPhotosTest` helper now seeds `frame_meta` for fake hits (the core fences photos; real recalls always have the row).

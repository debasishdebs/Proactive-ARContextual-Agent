## 14. Lessons from this session (so the next one avoids them)

- The photo-privacy invariant needs a structural choke point plus one declaration, not per-caller patches: already done for image calls, still to do for photo-derived text (section 6.2).
- Patching concurrency one race at a time looped for 6 Codex rounds; the fix that worked was a single serialised state machine with write-behind persistence.
- "Flaky" tests were real bugs (a tear-down that waited on an idle that never came).
- Check the user's real data (quality harness) before trusting a review: the biggest user-visible defects (semantic search never on, caption backlog) were setup/scheduling problems no unit test saw.
- Agents sometimes claim a restore/fix that did not happen: verify with `git diff` / grep.
- Wireless adb: a stale adb server needed `adb kill-server`; Android shows Wi-Fi off after a firmware update.

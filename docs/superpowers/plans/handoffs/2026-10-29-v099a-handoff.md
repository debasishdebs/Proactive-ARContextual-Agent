## What differs from LiveFit
- Wire: PCA's `WatchMotionMessage` (v 1, source `pca_watch`, random `epoch`, `seq` +1 per attempt), path `/pca/motion`. No LiveFit `Wire`, `WatchRuntime` or protocol 4.
- Sender: new `MotionSender` (pure, fake-testable): >= 1.1 s between attempts, backoff 1.1 s doubling to 30 s, 6 tries, always the latest state; a failed report stays `unsent` and the next tick resends. `WearPhoneLink` sends to all connected nodes (no node ids logged).
- On/off toggle: off clears the passive listener and cancels the alarms; the tick is ignored while off. Default on.
- Receiver is `exported=false` (boot/replace still delivered; the tick is an explicit intent). LiveFit's is exported.
- Manifest allowlist is exactly ACTIVITY_RECOGNITION and RECEIVE_BOOT_COMPLETED (no BODY_SENSORS, location, INTERNET, foreground service). Capability `pca_watch` in `res/values/wear.xml`.
- Logs: tag `PcWatch`, enum names and counts only.
- Build: `applicationId com.rokid.context`, minSdk 30, targetSdk 35, compileSdk 36, versionName 1.0.0, versionCode 21 (phone code 2 * 10 + 1). Lifecycle is pinned to 2.8.5 (as the phone) because 2.8.3 is not in the offline Gradle cache.
- UI: Compose for Wear status screen (state chip, last state, "sent N min ago", one toggle, "Grant motion access" button only when the permission is missing).

## Install on the watch (Galaxy Watch 6 Classic, debug sideload)
Placeholders only; take the real values from the watch screen, never write them here.
1. Watch: Settings > About watch > Software information, tap Software version 5 times; then Developer options: enable ADB debugging and Wireless debugging.
2. Wireless debugging > Pair new device shows `<PAIR_IP>:<PAIR_PORT>` and a `<PAIR_CODE>`.
3. `adb pair <PAIR_IP>:<PAIR_PORT>` and enter `<PAIR_CODE>` when asked.
4. `adb connect <WATCH_IP>:<CONNECT_PORT>` (the port on the Wireless debugging main screen differs from the pairing port). Check with `adb devices -l` and use `adb -s <WATCH_SERIAL_OR_IP:PORT>` for every command (serials can contain spaces; quote them).
5. `adb -s <WATCH> install -r android-companion/watch/build/outputs/apk/debug/watch-debug.apk`
6. `adb -s <WATCH> shell pm grant com.rokid.context android.permission.ACTIVITY_RECOGNITION` (or tap "Grant motion access" in the app).
7. Open the Context app once; then `adb -s <WATCH> logcat -s PcWatch` should show `registered dataTypes=N`, later `send <STATE> ok=true tries=1`.
8. The phone side lands in slice B; until then the watch sends but nothing accepts. The watch app and phone app must share applicationId and signing key (both debug-signed here).

## Fix 1: one log line per dropped watch message
`WatchDropLog` (in `WatchLinkState.kt`), tag `PcCtx`, line `watch drop reason=<token> n=<count>`. Fixed tokens only: `source_off, hub_down, bad_path, bad_version, stale_seq, rate, malformed, wrong_source` (internal `not_enabled`->source_off, `hub_off`->hub_down, `version`->bad_version, `bad_source`->wrong_source, `too_big`->malformed). At most one line per token per 60 s, carrying the count since that token's last line. No payload, state, node or path text is logged. `LogContentScanTest` has a reviewed forwarder entry for `WatchLinkState.kt`. Tests: `WatchDropLogTest`.

# Map zones P2 and P3 (ROADMAP 1.4.9): scope, build and owner questions

Status: 2026-11-25, branch `feat/v101-ask-eval`. Source: `2026-11-24-map-zones-screen-design.md` (section 9 phases, 2.5, 3, 5) and `handoffs/map-p1-2026-11-24.md`. Everything below is behind the Developer flag `mapZonesV2` (P1) plus the nested Developer flag `mapZonesP23` (both default OFF, also on a prefs error). Nothing was run on a device. Room schemas are untouched (context.db v18, places.db v3).

## 1. What P2 and P3 were in the design

| Phase | Design text | Ruling |
|---|---|---|
| P2 | "Download this area": `TileAreaMath`, `OfflineAreaStore`, `OfflineAreaDownloader`, download sheet, Delete-all hook | CANCELLED by the owner (offline map/tile download is not built; PMTiles sideload stays unused; the free MapTiler plan has no bulk download). Not built. |
| P3 | "My Moments" density layer with a date range bar, behind a setting | Built (the location field shipped in context.db v18, table `moment_location`). |
| P1 leftovers | Edit coordinates, double-tap zoom, "Also seed this area", seed Show cells, seed rename, undo/snap/overlap notes | Built where no schema change is needed (see 2). The rename part is parked (see 3). |

So "P2" in this build means the P1 leftovers that were promised but not built, plus the editing tools that make the draw/edit flow usable without a device test (undo, snap, overlap notes). P2 proper (downloads) does not exist any more.

## 2. Built now (all pure logic is unit tested; the Compose draw and gesture code is device-only)

New files in `phone/.../ui/settings/mapzones/`: `MapEdit.kt`, `MapDensity.kt`, `MapCells.kt`. Small additive edits to `MapZonesModel.kt`, `MapZonesScreen.kt`, `MapCanvas.kt`.

P2 tools (flag `mapZonesP23`):
- Undo / Redo of the DRAFT shape (`DraftHistory`): one drag is one step (events under 400 ms apart merge), 50 steps, dropped with the draft. Buttons "Undo" and "Redo" in the draft bar.
- Snap (`ShapeSnap`): a dragged rectangle edge or a moved circle centre snaps to the edges of other zones and seed areas within 10 dp; a move keeps its size; never produces an invalid shape; a resize of a circle is not snapped.
- Overlap notes (`ZoneOverlap`): Seed sheet "Part of this area is a pause zone: place cards stay off there." (design 3.2.5); Pause sheet notes overlap with other pause zones (both stay in force).
- Edit coordinates (`CoordinateFields`): South/West/North/East (circle: centre and radius) typed fields, same limits as dragging, up to 6 decimals, NaN/Infinity/exponents/antimeridian refused, one undoable step. Placement path for TalkBack in addition to the step actions.
- Double tap zooms x2 about the tapped point (`DoubleTap`).
- "Also seed this area" (design 3.1.4) from the pause sheet and from the selected pause zone: makes a separate Seed draft from the same box. The pause zone is not converted, not touched. A pause zone is now saved only from the Pause sheet (`savePause` returns when the sheet is not Pause).
- Show cells / Hide cells for the selected seed area (`SeedCoverage`, `CellCoverageViewModel`): each 5 km cell blue (ready), amber (partial), red dashed (not fetched), from a new read-only `PlacePack.cellStatuses(box)`; no fetch, no write. Areas above 4,000 cells say so and draw nothing.
- Accessibility: the Undo, Redo, coordinate, Also seed and Show cells controls carry text labels and test tags; the map's TalkBack actions from P1 are unchanged; spoken text still has counts only, never a name or a coordinate.

P3 (flag `mapZonesP23` and the user's own switch "Show my Moments on the map", default OFF, `DeveloperFlags.mapMomentsDensity`):
- Density blobs (`MomentDensity`): the saved Moment locations in the visible box and the date window are read through a new read-only `MomentLocationDao.pointsIn` (a query, not a schema change; at most 20,000 points; position and time only, never a Moment id, text or photo), counted per 40 px world-anchored cell, drawn as radial blobs purple (few) to orange (many), log scaled.
- Date window chips: 7 days, 30 days, All (ends at the newest saved location). Summary line "1,153 Moments - 19 Nov 2026 to 24 Nov 2026".
- Nothing is cached or stored: only the blobs of the current view are held, they are cleared when the switch goes off or the screen closes, and every visit and view change asks the database again, so a Forget shows at once. Switch OFF means no database read at all.

Fail-closed rules for P2 edits (the controller's `ZoneChange.BLOCKED_INSIDE` is unchanged and still decides):
- `ZoneEditPolicy` is stricter than the controller: a stored pause zone can be opened for reshaping only when its own row says clearly outside (CLEAR) or it is switched off; INSIDE, approaching (WARN), "not judged yet", a missing row, or unreadable saved zones all block it. It is checked when "Edit shape" is tapped AND again at every Save tap (you may have walked in meanwhile); the draft stays, the stored zone stays in force, no `upsert` is made.
- A reshape that makes the zone smaller shows a notice; undo, snap, coordinates and Also seed change the in-memory draft only and cannot reach the store. Only `MapZonesViewModel.savePause` calls `ZoneEditor.upsert` (guard test: still exactly one call site, and the new files do not mention the store or controller).

## 3. Parked (and why)

- Seed-area rename (and showing a name on the seed card and in the list): there is no name column. `AreaEntity(blueZoneId, south, west, north, east, seededAt, status)` has no name. Per the ruling I did not migrate. Options: (a) places.db v3 to v4, additive `name TEXT` (and `presetId TEXT`) columns with an AutoMigration/manual migration, exported schema, a migration test (the design's R9 recommendation; clean, travels with the area, removed with `removeArea`); (b) a small prefs/JSON map `seed_area_names: blueZoneId -> name` (no schema change; the pins use the `place_pins` prefs file, but that file is excluded from backup (BackupRulesTest), so a new file needs the same handling (backup exclusion, wipe on Forget, a test), and it can orphan when `removeArea` runs unless that call also clears it). I chose neither because both touch more than the map screen; seed cards keep their coordinate label.
- Seed "Edit shape": an area is keyed by its box (`seed:%.3f,...`), so reshaping would create a second area and orphan the first; needs the rename/identity decision above.
- Moments density hotspot tap (list the Moments of a blob with keyset paging): needs Moment ids; parked on purpose so the layer reads only positions and times.
- Offline map area layer, Download this area, PMTiles: cancelled (section 1).
- Per-cell seed progress ("4 of 6 cells"): `PlaceGuideControl.seed` does not pass `onProgress` through; untouched.
- Device checks owed (design section 8) are unchanged and still open, now also: double-tap vs tap-to-select feel, snap tolerance feel, density blob look and speed with a real 1,000+ Moment library, Show cells colours.

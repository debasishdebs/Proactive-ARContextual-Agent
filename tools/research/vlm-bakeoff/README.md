# Offline VLM bake-off (Nov 2026): scripts and results kept; model weights deleted
Scripts: fetch.py (downloads the public Wikimedia Commons test images listed in images.csv with licence and author), bake.py (asks a llama.cpp server with a VLM to pick the place among candidate names), analyze.py (summary). results_qwen3vl2b.csv = the Qwen3-VL-2B run (N=4).
Learnings: Qwen3-VL-2B got 2/3 present places right, one confident WRONG pick (0.85), and a false match (0.95) for an ABSENT place; its self-reported JSON confidence is not trustworthy -> score the answer token logprob instead. SmolVLM2: no usable result. Memory pressure on the 8 GB Mac made timing meaningless (17.5 s resident, thrashing otherwise): rerun on a quiet machine or on the phone. Weights (3 GB) were downloaded from Hugging Face by the scripts and are NOT kept; re-fetch when needed (see docs/superpowers/plans/2026-11-20-offline-vision-model-exploration.md for model names/quantisations).
